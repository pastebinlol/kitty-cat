# Desktop Cat v1.5 — original artwork, animated legs

The 12-frame walk cycles for Mochi, Luna, and Cocoa now derive DIRECTLY from their original v1.4 artwork. The front paws animate in opposing phases, with a smaller rear-leg counterstep. This preserves the original face, body, fur shading, palette, and proportions. No new cartoon legs or alternate character designs were drawn.

The sleep orientation fix from v1.4 is retained, as are ball sizing and purring.

Limit: This is still a localized image warp, not a fully independent articulated four-leg rig. Because the original art merges overlapping legs into the torso, a fully realistic crossing step requires hand-separated limb layers with painted-in hidden body areas.

Run: npm install && npm run tauri dev. Native macOS testing was not available.
